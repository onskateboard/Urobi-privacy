Credit deduction: Credits are deducted each time you use an AI-powered feature (image analysis, voice follow-up, text-to-speech). The amount deducted per request reflects the actual AI token usage.

Third-Party AI Services (OpenAI) – Data Sharing & User Consent

The Application delivers AI features through a backend service operated by the Service Provider, which in turn uses the API of OpenAI, L.L.C. ("OpenAI"), 3180 18th St, San Francisco, CA 94110, USA. You do not need to provide or manage an OpenAI API key.

What data is transmitted: When you actively use AI-assisted features, the following data is sent from the Application to the Service Provider's backend server, which then forwards it to OpenAI:

  • Camera images (resized) — when you tap "Photo" or "Text", a photo is captured and forwarded to OpenAI's Vision API.
  • Voice transcriptions (optional) — if you use Follow-Up mode, your voice is transcribed on-device; only the resulting text is forwarded.
  • Generated text for speech synthesis — the AI-generated description is forwarded to OpenAI's TTS API for spoken output.

No other personal data is sent.

Who receives it: Your content is sent to the Service Provider's backend server solely to deliver the requested AI feature, and from there to OpenAI, L.L.C. It is not sold or shared with any other third party.

Your explicit consent: Before you use the Application for the first time, it presents a clear notice describing all data that will be sent and requires your explicit permission. No data is transmitted without your prior, active consent. The Application's core features depend entirely on this AI service, so consent is required to use the Application.
